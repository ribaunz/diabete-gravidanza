# diabete-gravidanza

App gestionale per il diabete gestazionale.

## Stato

Bootstrap del repository. Contenuti in arrivo.

## Ambiente di sviluppo

- Stack: WAMP (Apache + MySQL + PHP)
- Percorso locale: `C:\wamp64\www\diabete-gravidanza`
- URL locale: http://localhost/diabete-gravidanza

## Setup

```bash
git clone https://github.com/ribaunz/diabete-gravidanza.git
```

Posizionare il clone dentro `C:\wamp64\www\` e avviare WAMP.
